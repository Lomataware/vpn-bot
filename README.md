# 🛡️ VPN Telegram Bot (VLESS Reality + Hysteria 2)

Асинхронный Telegram-бот для автоматической выдачи, продажи и продления VPN-подписок на базе **Marzban (Xray VLESS + Reality)** и **Hysteria 2** с поддержкой мультисерверной архитектуры (Master + Nodes).

---

## ✨ Основные возможности

* **Два протокола на одном порту (443):**
  * **VLESS + XTLS-Vision + Reality (`443/tcp`)** — маскировка под обычный HTTPS-трафик крупных сайтов без необходимости светить домен в SNI.
  * **Hysteria 2 (`443/udp`)** — протокол на базе QUIC для максимальной скорости на сложных мобильных и перегруженных сетях.
* **Собственный сервер авторизации Hysteria 2 (`hy2auth`):**
  * Легковесный HTTPS-бэкенд на `aiohttp`, проверяющий логины, пароли и сроки действия подписок напрямую по общей базе SQLite (режим `WAL`).
* **Пробный период (3 дня):**
  * Новым пользователям доступна кнопка `🎁 Пробный период (3 дня)` с защитой от повторной активации.
* **Бесшовное продление без смены ключей:**
  * При покупке или продлении подписки бот обновляет срок действия (`expire`) существующего профиля `tg_<user_id>`. Клиенту не нужно заново вставлять ссылки в приложение.
* **Оплата:**
  * 💳 Перевод на карту / по номеру телефона с подтверждением администратором в один клик (`/approve`).
  * ₿ Автоматический приём криптовалюты через **@CryptoBot** (выставление счёта в рублях с автоконвертацией в USDT, TON, BTC и др.).
* **Масштабирование (Master + Nodes):**
  * Скрипт `install_node.sh` и утилита `vpn-add-node` позволяют за пару минут подключить дополнительные серверы (локации) как для VLESS, так и для Hysteria 2.
* **Безопасность «из коробки»:**
  * Веб-панель Marzban привязана строго к `127.0.0.1:8000` (доступ только через SSH-туннель, Docker не пробивает UFW).
  * Встроенная блокировка BitTorrent-трафика в правилах маршрутизации Xray для защиты VPS от жалоб хостера.

## 🚀 Быстрый старт (Установка главного сервера)

### Требования
* Чистый VPS с **Ubuntu 22.04** или **24.04 LTS** (права `root`).
* Домен (или поддомен), **A-запись** которого уже направлена на IP-адрес сервера.
* Токен бота от [@BotFather](https://t.me/BotFather) и ваш личный Telegram ID (можно узнать в [@userinfobot](https://t.me/userinfobot)).

### Вариант 1: Интерактивная установка
Скачайте и запустите скрипт `install_vpn.sh` — он сам запросит нужные параметры:

```bash
curl -fsSL https://raw.githubusercontent.com/Lomataware/vpn-bot/main/install_vpn.sh -o install_vpn.sh
bash install_vpn.sh
```

### Вариант 2: Автоматическая установка без вопросов
Передайте переменные окружения перед запуском:

```bash
DOMAIN=de.example.com \
SERVER_LABEL="Germany" \
LE_EMAIL=admin@example.com \
BOT_TOKEN="123456789:ABCDEF..." \
ADMIN_ID=123456789 \
BOT_REPO="https://github.com/ВАШ_НИК/vpn-bot.git" \
SUPPORT_USERNAME="your_support" \
SUPPORT_PHONE="+79990000000" \
BANK_NAME="Т-Банк" \
PRICE_1_MONTH=100 \
TRIAL_DAYS=3 \
bash install_vpn.sh
```

Что сделает скрипт автоматически:
1. Проверит совпадение публичного IP сервера и DNS A-записи домена.
2. Установит Docker, системные зависимости и выпустит сертификат Let's Encrypt.
3. Настроит файрвол **UFW** (открыты только `22/tcp`, `80/tcp`, `443/tcp`, `443/udp`).
4. Установит **Marzban** с привязкой к `127.0.0.1:8000`, сгенерирует ключи X25519 для Reality, настроит статистику трафика, анти-торрент и зарегистрирует домен в разделе `Hosts`.
5. Установит **Hysteria 2** и свяжет её с локальным сервером авторизации `hy2auth`.
6. Развернёт бота в `/root/vpn_bot/vpntg`, создаст `.env` и запустит systemd-сервисы `vpnbot.service`, `hy2auth.service` и `hysteria.service`.
7. Сохранит все сгенерированные пароли и ключи в `/root/install_credentials.txt` (`chmod 600`).

## 🌍 Подключение второго сервера (Ноды)

Если вам нужно добавить ещё одну страну/локацию, вам не нужно поднимать второго бота.

### Шаг 1. Подготовка данных с главного сервера
На **главном сервере (Master)** посмотрите токен авторизации и клиентский сертификат Marzban:
```bash
cat /root/install_credentials.txt
cat /root/marzban_node_cert.pem
```

### Шаг 2. Запуск установщика на втором сервере
Направьте A-запись поддомена ноды (например, `nl.example.com`) на IP второго сервера и запустите на нём `install_node.sh`:

```bash
curl -fsSL https://raw.githubusercontent.com/Lomataware/vpn-bot/main/install_node.sh -o install_node.sh
bash install_node.sh
```
Скрипт запросит домен ноды, название локации, IP и домен главного сервера, `HY2_AUTH_TOKEN` и попросит вставить содержимое `/root/marzban_node_cert.pem`.

### Шаг 3. Привязка ноды на главном сервере
В конце установки `install_node.sh` выведет готовую команду. Выполните её на **главном сервере**:

```bash
vpn-add-node <IP_НОДЫ> <ДОМЕН_НОДЫ> "<НАЗВАНИЕ_ЛОКАЦИИ>"
# Пример:
vpn-add-node 185.10.20.30 nl.example.com "Netherlands"
```
Утилита автоматически откроет порт `9443/tcp` для IP ноды в UFW, зарегистрирует ноду в Marzban, добавит новый `Host` для генерации VLESS-ключей и допишет сервер в `HY2_SERVERS` бота.

## 👮 Команды администратора в Telegram

Команды доступны пользователям, чей Telegram ID указан в `ADMIN_ID` или `ADDITIONAL_ADMINS`:

| Команда | Описание |
| :--- | :--- |
| `/stats` | Статистика бота: всего пользователей, активных за сегодня, взявших триал, ожидающих и оплаченных платежей |
| `/pending` | Список заявок на ручную оплату картой со ссылками на быстрое подтверждение |
| `/approve <payment_id>` | Подтвердить оплату по номеру платежа и автоматически выдать/продлить подписку на 30 дней |
| `/issue <user_id> <days>` | Вручную выдать или продлить подписку пользователю `user_id` на указанное количество дней |
| `/broadcast <текст>` | Безопасная рассылка сообщения всем активным пользователям бота (с защитой от лимитов Telegram) |

## 🔧 Обслуживание и управление

### Доступ к веб-панели Marzban
В целях безопасности порт `8000` закрыт от внешнего мира. Чтобы открыть панель управления в браузере на своём компьютере, пробросьте SSH-туннель:

```bash
ssh -L 8000:127.0.0.1:8000 root@<IP_ГЛАВНОГО_СЕРВЕРА>
```
После этого откройте в браузере: `http://127.0.0.1:8000/dashboard/` (логин и пароль лежат в `/root/install_credentials.txt`).

### Полезные команды на сервере
```bash
# Просмотр логов в реальном времени
journalctl -u vpnbot -f        # Логи Telegram-бота
journalctl -u hy2auth -f       # Логи сервера авторизации Hysteria 2
journalctl -u hysteria -f      # Логи сервера Hysteria 2
marzban logs                   # Логи Marzban и ядра Xray

# Перезапуск сервисов
systemctl restart vpnbot hy2auth hysteria

# Обновление кода бота из Git-репозитория
bash /root/vpn_bot/vpntg/update.sh
```

## ⚙️ Переменные окружения (`.env`)

При установке через `install_vpn.sh` файл `.env` генерируется автоматически. При ручной настройке скопируйте `.env.example` в `.env`:

* `BOT_TOKEN` — токен Telegram-бота от `@BotFather`.
* `ADMIN_ID` — ваш числовой Telegram ID.
* `ADDITIONAL_ADMINS` — дополнительные ID администраторов через запятую.
* `SUPPORT_USERNAME`, `SUPPORT_PHONE`, `BANK_NAME` — контакт поддержки и реквизиты для ручной оплаты переводом.
* `MARZBAN_URL` — адрес панели (`http://127.0.0.1:8000` при локальной установке).
* `MARZBAN_ADMIN_USERNAME`, `MARZBAN_ADMIN_PASSWORD` — учётные данные администратора Marzban.
* `MARZBAN_VLESS_INBOUND` — тег VLESS-инбаунда в Marzban (по умолчанию `VLESS_INBOUND`).
* `DEFAULT_DATA_LIMIT_GB` — лимит трафика на подписку в ГБ (`0` — безлимит).
* `TRIAL_DAYS` — длительность бесплатного пробного периода в днях (по умолчанию `3`).
* `PRICE_1_MONTH` — стоимость подписки на 1 месяц в рублях.
* `CRYPTOBOT_ENABLED` — `true` или `false` (включение оплаты через `@CryptoBot`).
* `CRYPTOBOT_TOKEN` — API-токен приложения из `@CryptoBot` -> Crypto Pay.
* `CRYPTOBOT_TESTNET` — `false` для боевого режима, `true` для тестовой сети (`@CryptoTestnetBot`).
* `HY2_SERVERS` — список серверов Hysteria 2 в формате `domain1.com|Germany,domain2.com|Netherlands`.
* `HY2_PORT` — порт подключения клиентов Hysteria 2 (по умолчанию `443`).
* `HY2_AUTH_TOKEN` — секретный токен в URL между Hysteria 2 и `auth_server.py`.
* `HY2_AUTH_HOST`, `HY2_AUTH_PORT` — адрес и порт `auth_server.py` (по умолчанию `0.0.0.0` и `9443`).
* `HY2_AUTH_CERTFILE`, `HY2_AUTH_KEYFILE` — пути к `fullchain.pem` и `privkey.pem` сертификата Let's Encrypt.
